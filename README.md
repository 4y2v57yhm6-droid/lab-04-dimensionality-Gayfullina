## Описание

Исследование методов снижения размерности и регуляризации
логистической регрессии на задаче бинарной классификации
качества красного вина.
Предварительный и корреляционный анализ данных,
снижение размерности методом главных компонент (PCR),
L2-регуляризация логистической регрессии (ридж),
сравнение точности моделей по 10-блочной кросс-валидации,
прогноз на отложенной выборке и интерпретация коэффициентов
лучшей модели.

## Параметры варианта

- Набор данных: `winequality-red_for_lab` (красное вино, UCI «Wine Quality»)
- Зависимая переменная: `Y` — бинарный признак «хорошее / обычное вино» (1 / 0)
- Объясняющие переменные (9): `citric_acid`, `residual_sugar`, `chlorides`,
  `free_sulfur_dioxide`, `total_sulfur_dioxide`, `density`, `pH`,

- Метод снижения размерности: **PCR** (регрессия на главные компоненты)

- Разбиение: train (85%) / test (15%)
- Проверка точности: 10-блочная кросс-валидация (KFold, shuffle=True)

## Задача 4. Ридж-регрессия (L2)

### Постановка

Построить логистическую регрессию с L2-регуляризацией
на стандартизованных исходных признаках. Подобрать
оптимальное значение гиперпараметра `C` (инверсия λ)
методом 10-блочной кросс-валидации. Построить график
сжатия коэффициентов.

### Коэффициенты модели (без подбора C)

| Признак | Коэффициент |
|---|---|
| `alcohol` | +0.864 |
| `sulphates` | +0.604 |
| `free_sulfur_dioxide` | +0.354 |
| `citric_acid` | +0.231 |
| `residual_sugar` | +0.053 |
| `density` | −0.059 |
| `pH` | −0.153 |
| `chlorides` | −0.375 |
| `total_sulfur_dioxide` | −0.682 |

Константа модели: **+0.236**.

### Подбор гиперпараметра

| Параметр | Значение |
|---|---|
| `C_opt` | **2.783** |
| Тип регуляризации | L2 (`l1_ratio = 0`) |
| Метод подбора | 10-блочная CV, `scoring='accuracy'` |

### Оценка точности ридж-модели

| Модель | Метод оценки | Acc |
|---|---|---|
| `logit_ridge` | 10-блочная CV | **0.732** |

### Анализ графика сжатия коэффициентов

По мере роста `C` (уменьшения регуляризации) коэффициенты
«расходятся» из нуля; при малых `C` — сжимаются к нулю.
Оптимальное `C ≈ 2.78` (розовая линия) лежит в зоне,
где коэффициенты уже стабилизировались, но ещё не начали
переобучаться. Ни один коэффициент не обнуляется —
все 9 признаков остаются информативными.

### Интерпретация коэффициентов

Знак коэффициентов интерпретируется по стандартизованным
признакам:

- **Положительный вклад** в класс `Y = 1`: `alcohol` (+0.86),
  `sulphates` (+0.60), `free_sulfur_dioxide` (+0.35),
  `citric_acid` (+0.23).
- **Отрицательный вклад**: `total_sulfur_dioxide` (−0.68),
  `chlorides` (−0.38), `pH` (−0.15), `density` (−0.06).

Это согласуется с винодельческой логикой: более крепкие вина
с высоким содержанием сульфатов и низким содержанием
диоксида серы чаще попадают в класс «хороших».

## Задача 5. Сравнение моделей

### Постановка

Сравнить точность PCR и ридж-регрессии по результатам
10-блочной кросс-валидации и выбрать лучшую модель.

### Результаты

| Модель | Acc (10-блочная CV) |
|---|---|
| `logit_PCR` | 0.720 |
| **`logit_ridge`** | **0.732** ✅ |

### Анализ

Ридж-регрессия точнее PCR на **0.012** (≈1.2 п.п.).
Причина: ридж сжимает коэффициенты, но **не отбрасывает**
отдельные признаки, тогда как PCR при переходе к 6 ГК
теряет ≈10.4% исходной дисперсии — и вместе с ней
часть сигнала, полезного для классификации.

### Вывод

Лучшая модель — **`logit_ridge`**.

## Итоговые выводы по работе

1. **Классы сбалансированы** (`Y=1` — 53.5%, `Y=0` — 46.5%),
   пропусков нет, признаки требуют стандартизации
   из-за разных масштабов.
2. **6 главных компонент** объясняют 89.6% дисперсии
   исходных 9 признаков; этого достаточно для PCR
   без существенной потери структуры данных.
3. **PCR даёт Acc = 0.720** — рабочее, но не оптимальное
   качество. PCA максимизирует дисперсию, а не разделимость
   классов, поэтому часть сигнала теряется.
4. **Ридж-регрессия даёт Acc = 0.732** на 10-блочной CV
   и **0.70** на отложенных 240 наблюдениях. Оптимальное
   значение `C ≈ 2.78` соответствует умеренной
   L2-регуляризации: коэффициенты сжимаются, но не обнуляются.
5. **Интерпретация коэффициентов ридж-модели** соответствует
   винодельческой логике: `alcohol` и `sulphates` повышают
   шанс класса «хорошее вино», `total_sulfur_dioxide`
   и `chlorides` — понижают.
6. **Лучшая модель — `logit_ridge`**: она превосходит PCR
   как по кросс-валидации, так и по прогнозу
   на отложенной выборке.
